# DOOM WAD Engine

Браузерный движок DOOM на чистом JavaScript: загрузите любой WAD (IWAD + PWAD) кроме ZDOOM и играйте прямо в браузере — кооператив, сохранения, параметры запуска как в оригинале, поддержка мобильных.

![License: GPL-2.0](https://img.shields.io/badge/License-GPL_2.0-blue.svg)

## Возможности

- **Парсинг WAD** — читает структуру любого (кроме ZDOOM) IWAD и PWAD: уровни, текстуры, палитру. Файл остаётся на вашем устройстве и никуда не отправляется.
- **Сетевая игра** — кооператив на 2 игроков по короткому коду (WebRTC, с резервным TURN-ретранслятором, если прямое соединение не устанавливается).
- **Сохранения** — ручное сохранение и загрузка, продолжение с места сохранения.
- **Параметры запуска как в оригинале** — `-nomonsters`, `-fast`, `-respawn`.
- **Настройки** — качество графики, 5 уровней сложности, громкость звука и музыки, гамма, чувствительность мыши и сенсора, показ FPS.
- **Адаптивное качество** — при FPS ниже 30 качество снижается автоматически.
- **Прыжок** — опционально (в оригинале его не было).
- **Мобильное управление** — левая половина экрана: джойстик, правая: поворот.

## Быстрый старт

1. Запустите в любом браузере DOOM_WAD_Engine.html, выберите WAD-файл и играйте. 
2. Протестировать без загрузки можно тут: https://doomweb.neocities.org/ (единственно там не работает сглаживание)

> **Примечание.** Движок не распространяет ресурсы игры. Вам нужен собственный WAD-файл (например, `DOOM.WAD` из купленной игры) — либо полностью свободный [Freedoom](https://freedoom.github.io/).
